# Changelog

## 0.1.0

- Open a ToolJet Code mode app from a `vscode://`, `cursor://` or `windsurf://` link: sign in with the CLI, clone, install without install scripts, open, start dev.
- Commands: Open app, Start dev, Stop dev, Pull, Check (Problems panel), Publish, Install agent instructions.
- Status bar item with the linked app, its instance and the dev loop's state.
